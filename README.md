# Учебные проекты по Python

Репозиторий содержит учебные реализации алгоритмов машинного обучения, численных методов и решения задач с использованием NumPy.

## Содержание

- **`KNN.py`** — классификация методом k ближайших соседей (KNN) с визуализацией результатов.
- **`k-means.py`** — кластеризация методом K-means с визуализацией кластеров.
- **`mnk.py`** — аппроксимация данных линейной, степенной, показательной и квадратичной функциями; сравнение моделей по сумме квадратов ошибок.
- **`simplex.py`** — решение задач линейного программирования: минимизация затрат, максимизация прибыли и задача с пользовательскими ограничениями. Используется `scipy.optimize.linprog` с методом HiGHS dual simplex.
- **`numpy_tasks.py`** — практические задачи с массивами NumPy: работа с матрицами, анализ продаж и температурных данных, линейный прогноз.

## Технологии

Python · NumPy · Matplotlib · SciPy

## Запуск

Установить зависимости:

```bash
python -m pip install numpy matplotlib scipy
```

Запустить нужную программу:

```bash
python KNN.py
python k-means.py
python mnk.py
python simplex.py
python numpy_tasks.py
```

Некоторые программы запрашивают данные или номер задания через консоль. Для KNN и K-means используются случайно генерируемые данные, поэтому результаты могут меняться между запусками.
