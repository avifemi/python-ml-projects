# Учебные проекты по Python, численным методам и машинному обучению

Репозиторий содержит учебные реализации алгоритмов и лабораторные работы, выполненные в рамках университетских дисциплин. Это не production-проекты: код предназначен для изучения методов и экспериментов на небольших примерах.

## Содержание

### Машинное обучение
- `KNN.py` — простая реализация классификации методом k ближайших соседей (KNN) с визуализацией точек и предсказанных классов.
- `k-means.py` — реализация алгоритма кластеризации K-means и визуализация полученных кластеров.

### Численные методы и оптимизация
- `mnk.py` — аппроксимация набора точек линейной, степенной, показательной и квадратичной функциями; сравнение моделей по сумме квадратов ошибок.
- `simplex.py` — учебные задачи линейного программирования с использованием `scipy.optimize.linprog`.

### Python и NumPy
- `numpy.py` — упражнения с массивами NumPy и анализом небольших наборов данных.
- `lab_1.py`, `lab_2.py` — базовые задачи на условия, циклы, функции, списки, множества и словари.

## Используемые технологии

- Python
- NumPy
- Matplotlib
- SciPy

## Запуск

Установите зависимости:

```bash
python -m pip install numpy matplotlib scipy
```

Запустите нужный скрипт:

```bash
python KNN.py
python k-means.py
python mnk.py
python simplex.py
```

Часть программ запрашивает номер задания или данные через консоль. Скрипты KNN и K-means генерируют случайные двумерные данные, поэтому результаты визуализации могут отличаться при каждом запуске.

## Примечание

Репозиторий отражает учебные работы и освоение базовых алгоритмов. Перед использованием в качестве самостоятельного портфолио код требует дополнительной проверки, тестирования и улучшения структуры.
